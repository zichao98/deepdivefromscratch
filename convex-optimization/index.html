Convex Optimization
Why It Matters in ML

Convexity turns optimization into a promise: every local minimum is global. Explore that promise using the chord test below.

Test the chord

Pick a function, then move the two points. A convex function always stays at or below the line joining any two points.

1. Convex set

A set is convex when the full line segment between every pair of its points stays inside the set.

2. Convex function

For all points and mixes, f(λx₁+(1−λ)x₂) ≤ λf(x₁)+(1−λ)f(x₂).

3. ML payoff

Linear regression with squared loss is convex, so optimization has no bad local minima to trap us.
