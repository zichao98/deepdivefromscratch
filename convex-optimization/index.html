Convexity from zero to hero

Gradient descent always walks downhill — but downhill to where? This lesson answers the question every optimizer asks: is the bottom I found the lowest one? For one special family of problems, the answer is always yes.

The trap: which bottom?

Goal: see how gradient descent can get stuck, and why that's a real problem.

Gradient descent only ever looks at the ground under its feet. In a landscape with several valleys, it rolls into whichever one is nearest — a local minimum — and stops, even if a much deeper valley, the global minimum, is next door.

Remember

  • Gradient descent finds a minimum — the one whose valley you started in.
  • On a convex function, all roads lead to the single global minimum.
1Chapter 1

The chord test

Goal: learn the precise definition of a convex function — with a ruler.

📏

Think of it like

Lay a straight ruler between any two points on the curve. If the curve never pokes up above the ruler — for every pair of points you could pick — the function is convex. A bowl passes; a hill or a wave fails somewhere.

That ruler is called a chord. In symbols: for any two points \(a, b\) and any mix \(t\) between 0 and 1,

\[ f\big(t\,a + (1-t)\,b\big) \;\le\; t\,f(a) + (1-t)\,f(b) \]

The left side is the curve at a point between \(a\) and \(b\); the right side is the chord at that same point. "Curve below chord, always."

2Chapter 2

A faster test: curvature

Goal: check convexity without trying every chord.

Trying every chord is slow. For smooth functions there's a shortcut: look at how the slope changes. If the slope only ever increases as you move right, the curve keeps bending upward like a smile — and it's convex. How fast the slope changes is the second derivative \(f''(x)\):

\[ f''(x) \ge 0 \text{ for every } x \quad\Longleftrightarrow\quad f \text{ is convex} \]

🧭

In many dimensions

With many parameters, the second derivative becomes a matrix of curvatures, the Hessian. The function is convex when every direction curves upward — mathematically, when all the Hessian's eigenvalues are ≥ 0. For \(0.1\theta_1^2 + 2\theta_2^2\) from the Gradient Descent lesson, the curvatures are 0.2 and 4: both positive, so it's convex.

Check your understanding

\(f(x) = x^3\). Is it convex over all real numbers?

Remember

  • Smooth function: convex ⇔ second derivative never negative (smiles everywhere).
  • Many dimensions: every direction must curve upward (Hessian eigenvalues ≥ 0).
3Chapter 3

Convex sets

Goal: understand convexity for regions — the shape of the "allowed" area.

Real problems often have rules: budgets, limits, "weights must be positive". The allowed region is a set. A set is convex if the straight line between any two points inside it stays inside it. A disk is convex; a star or a crescent isn't.

Why care? A convex function on a convex set is the gold standard of optimization: if you minimize a bowl over a disk-like region, there's still exactly one best answer and fast algorithms that find it. Non-convex constraints can hide the best answer behind a corner.

Remember

  • Convex set: the segment between any two members stays inside.
  • Convex function + convex set = a problem with no hidden traps.
4Chapter 4

Why convex means global

Goal: prove — in plain steps — that a convex function has no local traps.

Every local minimum of a convex function is global

  1. Suppose gradient descent stopped at a local minimum \(a\), but somewhere there's a lower point \(b\) with \(f(b) < f(a)\). We'll show this is impossible.

  2. \[ f\big(t\,b + (1-t)\,a\big) \le t\,f(b) + (1-t)\,f(a) \]

    Apply the chord rule between \(a\) and \(b\). This holds for every \(t\) from 0 to 1.

  3. \[ t\,f(b) + (1-t)\,f(a) \;<\; f(a) \quad\text{for any } t > 0 \]

    Because \(f(b) < f(a)\), any mix that includes some of \(b\) is lower than \(f(a)\).

  4. Take \(t\) tiny: the point \(t b + (1-t) a\) is right next to \(a\), yet lower than \(a\). So \(a\) had a lower neighbour — it wasn't a local minimum after all. Contradiction.

  5. Therefore no lower point \(b\) exists: any local minimum of a convex function is a global minimum. If gradient descent stops, it's done.

🔍

Fine print

A convex function can have a flat bottom (many equally good minima, like \(|x|\) stretched out) or none at all (\(e^x\) keeps falling to the left). Strictly convex functions — which curve upward everywhere — have at most one minimum.

5Chapter 5 · Advanced

Speed: the condition number

Goal: predict how fast gradient descent converges on a convex bowl.

Convexity guarantees we reach the bottom — but not how fast. That depends on the bowl's shape. If the steepest direction curves \(L\) and the gentlest curves \(\mu\) (a function with \(\mu > 0\) is called strongly convex), their ratio is the condition number:

\[ \kappa = \frac{L}{\mu}, \qquad \text{error shrinks by } \frac{\kappa - 1}{\kappa + 1} \text{ each step (best learning rate)} \]

\(\kappa = 1\) is a perfectly round bowl — one step reaches the bottom. Large \(\kappa\) is a long, narrow valley where progress crawls.

Convexity in machine learning

Some of the most-used models have convex losses; deep networks do not. Test them yourself: the lab slices each loss along one weight and runs thousands of chord tests automatically.

So why do neural networks train at all? In practice their landscapes have many minima that are about equally good, and tricks like momentum, noise from mini-batches and good initialisation help avoid bad ones. But there are no guarantees — which is exactly why convex models remain popular when they're good enough.

Remember

  • Convex: linear regression (MSE), logistic regression, SVMs, lasso/ridge.
  • Non-convex: neural networks. Different starts can give different results.

Cheat sheet & final challenge

Convex function

\(f(ta+(1-t)b) \le tf(a)+(1-t)f(b)\): curve below every chord.

Quick test

\(f''(x) \ge 0\) everywhere (Hessian eigenvalues ≥ 0 in many dimensions).

Convex set

The segment between any two points stays inside.

The guarantee

Every local minimum is global. Gradient zero ⇒ done.

Speed

\(\kappa = L/\mu\); error × \((\kappa-1)/(\kappa+1)\) per step.

In ML

Linear & logistic regression: convex. Neural nets: not.
