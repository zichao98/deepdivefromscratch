Convex Optimization — Why It Matters in ML

An interactive journey through convexity, the chord inequality, and why convex objectives guarantee a global minimum

→ → → → →

Step 1 — What is a Convex Function? Definition

A function is convex if the line segment between any two points on its graph lies above or on the graph. Switch between convex and non-convex examples to see the difference.

f(x) x

Formal definition

A function \(f: \mathbb{R}^n \to \mathbb{R}\) is convex if for all \(\mathbf{x}, \mathbf{y}\) and \(\lambda \in [0,1]\):

\[ f(\lambda \mathbf{x} + (1-\lambda)\mathbf{y}) \leq \lambda f(\mathbf{x}) + (1-\lambda) f(\mathbf{y}) \]

The right-hand side is the chord — the linear interpolation between the two points. Convexity demands the function always stays below this chord.

This function IS convex ✓

Step 2 — The Chord Inequality (Jensen's Inequality) Interactive test

Move the sliders to place two points on the function and a mixture point between them. The chord test checks whether the function value at the mixture is below the linear interpolation.

f(x) x

The chord test

For points \(x_1\) and \(x_2\), the mixture point is:

\[ x_\lambda = \lambda x_1 + (1-\lambda) x_2 \]

The chord value at \(x_\lambda\) is the linear interpolation:

\[ \text{chord} = \lambda f(x_1) + (1-\lambda) f(x_2) \]

Convexity requires: \(f(x_\lambda) \leq \text{chord}\)

Step 3 — Convex Sets Geometric intuition

A set is convex if the line segment between any two points in the set also lies entirely within the set. Click inside the canvas to add points — the convex hull is drawn automatically.

Convex hull visualization Click to add points

Convex set definition

A set \(\mathcal{C} \subseteq \mathbb{R}^n\) is convex if for all \(\mathbf{x}, \mathbf{y} \in \mathcal{C}\) and \(\lambda \in [0,1]\):

\[ \lambda \mathbf{x} + (1-\lambda)\mathbf{y} \in \mathcal{C} \]

The convex hull of a set of points is the smallest convex set containing all of them. It is formed by taking all possible line segments between the points.

The teal shaded region is the convex hull of your points. Any line segment between two points inside this region stays inside it.

Step 4 — Why Convexity Guarantees a Global Minimum The key theorem

For convex functions, every local minimum is a global minimum. For non-convex functions, gradient descent can get trapped in local minima. Compare the two cases interactively.

f(x) x

The guarantee

For a convex function, if \(\nabla f(\mathbf{x}^*) = \mathbf{0}\), then \(\mathbf{x}^*\) is a global minimum. There are no local minima that are not global.

\[ \nabla f(\mathbf{x}^*) = \mathbf{0} \implies f(\mathbf{x}^*) = \min_{\mathbf{x}} f(\mathbf{x}) \]

For a non-convex function, a point with zero gradient could be a local minimum, a local maximum, or a saddle point. Gradient descent might converge to a bad local minimum.

Convex: one global minimum at x = 0

This is why ML prefers convex loss functions — optimization is reliable and efficient.

Step 5 — Strong Convexity & the Condition Number Convergence rate

The condition number κ determines how "elliptical" the loss surface is. A high condition number means slow, oscillating convergence for gradient descent. Adjust κ and watch the effect.

θ₁ θ₂

Condition number

For a quadratic loss \(L = \frac{1}{2}\theta_1^2 + \frac{\kappa}{2}\theta_2^2\), the condition number is \(\kappa\).

\[ \kappa = \frac{\lambda_{\max}}{\lambda_{\min}} \]

where \(\lambda_{\max}\) and \(\lambda_{\min}\) are the largest and smallest eigenvalues of the Hessian.

κ = 4: mild oscillation

κ = 1: perfectly circular — GD converges in one step.
κ ≫ 1: highly elliptical — GD oscillates heavily and converges slowly.

This is why preconditioning and adaptive optimizers like Adam are so important in deep learning!

Step 6 — Convex Optimization in Machine Learning Real applications

Many core ML problems are convex optimization problems. Click on each card to see its loss function and why it is convex.

Linear Regression (OLS)

The squared loss \(L = \|\mathbf{X}\boldsymbol{\beta} - \mathbf{y}\|^2\) is a convex quadratic in \(\boldsymbol{\beta}\). The Hessian \(\mathbf{X}^T\mathbf{X}\) is positive semi-definite, guaranteeing convexity.

\[ \min_{\boldsymbol{\beta}} \|\mathbf{X}\boldsymbol{\beta} - \mathbf{y}\|^2 \]

Logistic Regression

The cross-entropy loss is convex in the weight parameters. The negative log-likelihood is a sum of convex log-sigmoid terms, and sums of convex functions are convex.

\[ \min_{\mathbf{w}} -\sum_i \log \sigma(y_i \mathbf{w}^T \mathbf{x}_i) \]

Support Vector Machine

The SVM hinge loss with L2 regularization is a convex quadratic program. The dual problem is also convex, enabling efficient kernel methods.

\[ \min_{\mathbf{w}} \frac{1}{2}\|\mathbf{w}\|^2 + C\sum_i \max(0, 1-y_i\mathbf{w}^T\mathbf{x}_i) \]

LASSO Regression

LASSO adds an L1 penalty to OLS. The L1 term is convex (but not smooth), making the overall problem convex. This promotes sparsity in the solution.

\[ \min_{\boldsymbol{\beta}} \|\mathbf{X}\boldsymbol{\beta} - \mathbf{y}\|^2 + \lambda \|\boldsymbol{\beta}\|_1 \]

Non-Convex: Neural Networks

Deep neural networks have non-convex loss surfaces with many local minima and saddle points. This is why optimizers like Adam, with momentum and adaptive learning rates, are essential.

\[ L(\boldsymbol{\theta}) \text{ is non-convex for deep nets} \]

Why it matters

For convex problems, we can prove convergence rates, guarantee global optima, and use efficient algorithms like interior point methods. For non-convex problems (deep learning), we rely on heuristics and hope for the best.

\[ \text{Convex} \Rightarrow \text{guaranteed global minimum} \] \[ \text{Non-convex} \Rightarrow \text{no guarantees} \]
