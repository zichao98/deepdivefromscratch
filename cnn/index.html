CNNs from zero to hero

How does a computer see a cat? It slides tiny pattern detectors across the image, keeps the strongest signals, and stacks that trick layer after layer. That's a convolutional neural network — and by the end you'll build one that recognises your own drawings.

0Chapter 0

An image is a grid of numbers

Goal: see images the way a computer does.

To a computer, a black-and-white image is a grid of pixels, each holding a number: 0 for black, 1 for white (or 0–255). A colour image is three such grids stacked — red, green and blue — called channels. That's all "seeing" starts from.

Why not feed these numbers straight into the neural network from the Backpropagation lesson? A modest 1000 × 1000 photo has a million pixels. Connecting every pixel to just 1000 neurons needs a billion weights — and the network would have to learn "cat ear" separately for every position in the image. We need something smarter.

Remember

  • An image is a grid of numbers per channel (1 for grayscale, 3 for colour).
  • Fully connecting every pixel is wasteful and ignores that patterns can appear anywhere.
1Chapter 1

Convolution: sliding a pattern detector

Goal: compute a convolution and predict what a kernel will detect.

🔦

Think of it like

A small stencil sliding over the picture. At each spot you ask "how much does this patch look like my stencil?" and write the answer down. The page of answers is a map of where the pattern appears.

The stencil is a small grid of weights called a kernel (or filter). At each position, multiply every kernel weight by the pixel under it and add everything up. Slide one step, repeat. The grid of results is a feature map:

\[ Z_{i,j} = \sum_{a=0}^{2}\sum_{b=0}^{2} X_{i+a,\,j+b}\, K_{a,b} \]

2Chapter 2

ReLU: keep only the positive evidence

Goal: understand the activation step every CNN layer uses.

After convolution, CNNs apply ReLU to every value: \(\text{ReLU}(z) = \max(0, z)\). Negative numbers become 0, positive ones pass unchanged. Read it as "keep only the places where the pattern was found". It also adds the non-linearity that lets stacked layers learn more than a single layer could — and, as the Backpropagation lesson showed, it keeps gradients from vanishing.

3Chapter 3

Pooling: summarise and shrink

Goal: shrink feature maps while keeping the important signals.

Max pooling splits the map into small windows (usually 2 × 2) and keeps only the largest value in each. The map shrinks 4× in area, the next layer has less to process, and a pattern shifted by a pixel still gives the same result — a little translation invariance.

4Chapter 4

Stride, padding and output size

Goal: predict the size of any convolution's output.

Two knobs control the output size. Stride is how many pixels the kernel jumps each step. Padding adds a border of zeros so the kernel can also sit on the edges. For an \(N \times N\) input, \(K \times K\) kernel, padding \(P\) and stride \(S\):

\[ \text{output} = \left\lfloor \frac{N + 2P - K}{S} \right\rfloor + 1 \]

  • Padding (K − 1)/2 with stride 1 keeps the size; stride 2 roughly halves it.
5Chapter 5

Many filters, many channels

Goal: understand how real CNN layers are shaped.

One kernel finds one pattern. A real layer uses many kernels at once — say 32 — producing 32 feature maps stacked as 32 channels. The next layer's kernels then look across all 32 channels at once: a kernel is really \(3 \times 3 \times C_{\text{in}}\) numbers, and it combines simple features into more complex ones.

🧱

The hierarchy

Layer 1 finds edges and colour blobs. Layer 2 combines edges into corners and curves. Layer 3 combines those into textures and parts like eyes or wheels. Deeper layers respond to whole objects. Nobody designs these filters: they're learned by backpropagation, exactly as in the previous lesson.

Counting parameters

  1. \[ \text{params} = (K \times K \times C_{\text{in}} + 1) \times C_{\text{out}} \]

    Each of the \(C_{\text{out}}\) kernels has \(K \cdot K \cdot C_{\text{in}}\) weights plus one bias.

  2. \[ (3 \cdot 3 \cdot 3 + 1) \times 32 = 896 \]

    A first layer on a colour image with 32 filters: under a thousand numbers.

  3. \[ 224 \cdot 224 \cdot 3 \times 32 \approx 4.8 \text{ million} \]

    A fully-connected layer from the same image to just 32 neurons. The convolution uses about 5,000× fewer weights — and works at every position.

Check your understanding

A layer takes 64 channels in and produces 128 channels with 3 × 3 kernels. How many weights (ignoring biases)?

6Chapter 6 · Hero level

A CNN that reads your drawing

Goal: trace an image through a complete CNN to a prediction.

Here's a complete (tiny) CNN: conv with two kernels (a vertical-stroke and a horizontal-stroke detector) → ReLU → global max pool (the strongest response of each map) → flatten into 2 numbers → a fully-connected layer that turns them into scores for three classes → softmax to turn scores into probabilities. The weights are set by hand here so you can read them; a real CNN learns them.

  2. Draw a horizontal line it recognises.

  4. Try a diagonal. Why is the CNN confused?

The diagonal confuses it because neither of its two kernels detects diagonals — a real CNN would learn dozens of kernels, including diagonal ones. Thick strokes confuse it too, because the kernels were tuned to 1-pixel lines. Learning the kernels from thousands of examples, rather than hand-picking them, is exactly what training fixes.

Remember

  • CNN pipeline: conv → ReLU → pool (repeat) → flatten → fully-connected → softmax.
  • Features are only as good as the kernels; training learns the kernels.
7Chapter 7

Cheat sheet & final challenge

Convolution

Slide a K×K kernel; multiply-and-add at each position.

ReLU

\(\max(0, z)\): keep positive evidence.

Max pooling

Keep the max of each 2×2 window; map shrinks 4×.

Output size

\(\lfloor (N + 2P - K)/S \rfloor + 1\).

Parameters

\((K^2 C_{\text{in}} + 1)\, C_{\text{out}}\), independent of image size.

Pipeline

conv → ReLU → pool → … → flatten → dense → softmax.
