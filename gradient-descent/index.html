Step 1 — The Loss Surface 2D quadratic bowl

Every optimization problem starts with a loss function. Here we use a 2D quadratic bowl. Click anywhere on the canvas to set a starting point — the optimizer will walk from there.

θ₁ (parameter 1) θ₂ (parameter 2)

What is a loss surface?

A loss function \(L(\boldsymbol{\theta})\) measures how bad our model's parameters \(\boldsymbol{\theta}\) are. The loss surface plots this value for every possible parameter combination.

\[ L(\theta_1, \theta_2) = \frac{1}{2}\theta_1^2 + 2\theta_2^2 \]

This is a convex quadratic bowl — the global minimum is at \((0, 0)\) where \(L = 0\).

The elliptical shape comes from the different coefficients: the loss grows 4× faster along \(\theta_2\) than \(\theta_1\). This will matter a lot for gradient descent!

Step 2 — The Gradient Direction of steepest ascent

The gradient \(\nabla L\) is a vector of partial derivatives. It points in the direction of steepest ascent. Gradient descent moves in the opposite direction.

θ₁ θ₂

Computing the gradient

The gradient is the vector of partial derivatives with respect to each parameter:

\[ \nabla L = \begin{pmatrix} \frac{\partial L}{\partial \theta_1} \\[6pt] \frac{\partial L}{\partial \theta_2} \end{pmatrix} \]

For our loss function \(L = \frac{1}{2}\theta_1^2 + 2\theta_2^2\):

\[ \frac{\partial L}{\partial \theta_1} = \theta_1 \] \[ \frac{\partial L}{\partial \theta_2} = 4\theta_2 \]

Notice how the gradient is steeper along \(\theta_2\) — this causes oscillation in vanilla GD!

Step 3 — Vanilla Gradient Descent θ ← θ − α∇L

The simplest optimizer: take a step proportional to the negative gradient. Adjust the learning rate and watch how it affects convergence.

θ₁ θ₂

The update rule

At each step, update parameters by moving against the gradient:

\[ \boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \alpha \, \nabla L(\boldsymbol{\theta}_t) \]

where \(\alpha\) is the learning rate — the step size.

Too small α: painfully slow convergence.
Too large α: overshooting and divergence.
Just right: smooth descent — but note the oscillation along θ₂!

Step 4 — Momentum v ← βv + ∇L

Momentum accumulates a velocity vector across steps, smoothing out oscillations and accelerating convergence in the relevant direction.

θ₁ θ₂

How momentum works

Instead of using the raw gradient, momentum maintains a velocity vector \(\mathbf{v}\) that accumulates gradients over time:

\[ \mathbf{v}_{t+1} = \beta \mathbf{v}_t + \nabla L(\boldsymbol{\theta}_t) \] \[ \boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \alpha \, \mathbf{v}_{t+1} \]

where \(\beta\) is the momentum coefficient (typically 0.9).

Step 0 | L = —

The oscillations along \(\theta_2\) cancel out because momentum averages successive gradients — positive and negative gradients cancel, while the consistent gradient along \(\theta_1\) accumulates.

Step 5 — Adam Optimizer Adaptive moments

Adam combines momentum (first moment) with an adaptive per-parameter learning rate (second moment). It is the most widely used optimizer in deep learning.

θ₁ θ₂

The Adam update

Adam maintains two moving averages for each parameter:

First moment (momentum): \[ \mathbf{m}_t = \beta_1 \mathbf{m}_{t-1} + (1-\beta_1)\nabla L_t \] Second moment (variance): \[ \mathbf{v}_t = \beta_2 \mathbf{v}_{t-1} + (1-\beta_2)(\nabla L_t)^2 \] Bias-corrected update: \[ \hat{\mathbf{m}}_t = \frac{\mathbf{m}_t}{1-\beta_1^t}, \quad \hat{\mathbf{v}}_t = \frac{\mathbf{v}_t}{1-\beta_2^t} \] \[ \boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \alpha \frac{\hat{\mathbf{m}}_t}{\sqrt{\hat{\mathbf{v}}_t} + \epsilon} \]

The second moment rescales each parameter's update by its gradient magnitude. Parameters with large gradients get smaller effective steps — this automatically dampens the \(\theta_2\) oscillation!

Typical defaults: \(\beta_1 = 0.9\), \(\beta_2 = 0.999\), \(\epsilon = 10^{-8}\).
