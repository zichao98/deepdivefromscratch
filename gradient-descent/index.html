The calculation

For this bowl, L(x, y) = 0.5x² + 2y², so ∇L = (x, 4y). Plain gradient descent applies θₜ₊₁ = θₜ − α∇L(θₜ). Momentum retains a fraction of the last velocity; Adam rescales the update using moving gradient moments.
