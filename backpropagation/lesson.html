Backpropagation from zero to hero

A neural network can have billions of weights. To learn, it needs to know how every single one affects the error — and it gets all of them in one backward sweep. That sweep is backpropagation, and by the end of this lesson you'll run it by hand.

Why we need backpropagation

Goal: feel why measuring gradients one weight at a time is hopeless.

Gradient descent needs the slope of the loss for every weight. The obvious way to measure one slope: nudge that weight a tiny bit, run the network again, and see how much the loss changed. Try it on a small network with 9 adjustable numbers.

Each slope cost two runs of the network. A modern model has around a billion weights — that's two billion runs per update. Backpropagation computes all the slopes exactly in roughly the cost of two runs: one forward, one backward. It's the reason deep learning is possible at all.

Remember

  • Training needs \(\partial L / \partial w\) for every weight \(w\).
  • Nudging costs one extra run per weight. Backprop gets them all in one backward pass.
1Chapter 1

One neuron

Goal: know exactly what a single artificial neuron computes.

A neuron does two things. First it takes a weighted sum of its inputs plus a bias: \(z = w_1 x_1 + w_2 x_2 + b\). Then it squashes \(z\) through an activation function. We'll use the sigmoid, which turns any number into something between 0 and 1:

\[ \sigma(z) = \frac{1}{1 + e^{-z}} \]
🗳️

Think of it like

A neuron is a tiny committee vote. Each input is a voter, each weight says how much that voter counts (negative weights vote against), the bias is the committee's own leaning, and the sigmoid turns the tally into a confidence between 0 and 1.

2Chapter 2

The chain rule, backwards

Goal: learn the single trick behind backpropagation on a three-number example.

Any calculation can be drawn as a computation graph: boxes for operations, arrows for values. Take \(f = (a + b) \cdot c\). Going forward we compute \(q = a + b\), then \(f = q \cdot c\).

Going backward, we ask each box: "if your output changes a little, how much does your input change it?" That's its local derivative. The chain rule says the effect of a far-away input is just the product of the local derivatives along the path:

\[ \frac{\partial f}{\partial a} = \frac{\partial f}{\partial q}\cdot\frac{\partial q}{\partial a} = c \cdot 1 \]
⚙️

Think of it like

Gears. If gear A turns gear B 3× as fast, and B turns C 2× as fast, then A turns C 3 × 2 = 6× as fast. Backprop just multiplies gear ratios, starting at the output and walking back.

3Chapter 3

A real network: the forward pass

Goal: compute a small network's prediction and loss, number by number.

Wire neurons in layers: 2 inputs → 2 hidden neurons → 1 output neuron. The weights into the hidden layer are \(w_{jk}\) (hidden neuron \(j\), input \(k\)); the weights into the output are \(v_j\). The output \(\hat y\) is the network's probability that the answer is "yes", and the true answer is \(y = 1\).

To score it we use binary cross-entropy: \(L = -\big[y\ln\hat y + (1-y)\ln(1-\hat y)\big]\). If \(y = 1\) it's simply \(-\ln \hat y\): zero when the network is certain and right, huge when it's certain and wrong.

4Chapter 4

The backward pass

Goal: compute the gradient of every weight — and prove it's right.

Backprop through our network

  1. \[ \delta_o = \frac{\partial L}{\partial z_o} = \hat y - y \]

    The error signal at the output. Sigmoid and cross-entropy were made for each other: their derivatives multiply out to this beautifully simple result.

  2. \[ \frac{\partial L}{\partial v_j} = \delta_o \cdot h_j \]

    \(z_o = \sum v_j h_j + c\), so the local derivative of \(z_o\) with respect to \(v_j\) is \(h_j\). Multiply by the signal arriving from above.

  3. \[ \delta_j = \delta_o \cdot v_j \cdot \sigma'(z_j), \qquad \sigma'(z) = \sigma(z)\big(1-\sigma(z)\big) \]

    Pass the signal back into hidden neuron \(j\): through the weight \(v_j\), then through its sigmoid.

  4. \[ \frac{\partial L}{\partial w_{jk}} = \delta_j \cdot x_k \]

    Same rule as step 2, one layer down. Every weight's gradient is (signal at its output end) × (value at its input end).

  • Gradient of a weight = signal at its output end × value at its input end.
  • Signals travel back through weights and activation derivatives.
5Chapter 5

Train it: learning XOR

Goal: watch forward, backward and update repeat until a network learns something a single neuron can't.

XOR outputs 1 when exactly one of two inputs is 1. No single straight line separates its answers, so one neuron can't learn it — but a hidden layer can. Each epoch runs forward and backward on all four examples, then updates every weight with gradient descent.

  • Hidden layers let networks learn shapes a single neuron can't; their losses are non-convex.
6Chapter 6 · Hero level

Vanishing gradients

Goal: see why early deep networks wouldn't train, and what fixed it.

In a deep network, the gradient reaching layer 1 is a product of one factor per layer — and each sigmoid layer contributes \(\sigma'(z) \le 0.25\). Multiply twenty numbers smaller than 0.25 and you get almost nothing: the early layers stop learning. This is the vanishing gradient problem.

\[ \frac{\partial L}{\partial \text{layer}_1} \;\propto\; \prod_{\ell=2}^{D} w_\ell\,\sigma'(z_\ell) \]

The fix that unlocked deep learning was the ReLU activation, \(\max(0, z)\), whose slope is exactly 1 for positive inputs — so the product doesn't shrink.

7Chapter 7

Cheat sheet & final challenge

Neuron

\(z = \sum w_i x_i + b\), \(a = \sigma(z)\).

Chain rule

Multiply local derivatives along the path from output to input.

Output signal

Sigmoid + cross-entropy: \(\delta_o = \hat y - y\).

Weight gradient

Signal at the output end × value at the input end.

Hidden signal

\(\delta_j = (\sum \delta_{\text{next}} \cdot w) \cdot \sigma'(z_j)\).

Deep nets

Use ReLU-family activations to avoid vanishing gradients.
