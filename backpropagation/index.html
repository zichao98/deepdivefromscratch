Step 1 — The Neural Network 2-3-1 architecture

We use a simple network: 2 inputs, 3 hidden neurons (with sigmoid activation), and 1 output (with sigmoid). Adjust the weights and inputs to see how the network is wired.

Network architecture

Our network has three layers:

Input layer: 2 neurons (\(x_1, x_2\))

Hidden layer: 3 neurons with sigmoid activation \(\sigma(z) = \frac{1}{1+e^{-z}}\)

Output layer: 1 neuron with sigmoid activation

\[ z_j^{(1)} = \sum_i w_{ji}^{(1)} x_i + b_j^{(1)} \] \[ a_j^{(1)} = \sigma(z_j^{(1)}) \] \[ z^{(2)} = \sum_j w_j^{(2)} a_j^{(1)} + b^{(2)} \] \[ \hat{y} = \sigma(z^{(2)}) \]

Step 2 — Forward Pass Compute activations

Data flows left to right. Each neuron computes a weighted sum of its inputs, then applies the sigmoid activation function. Every value is calculated live.

How the forward pass works

For each hidden neuron \(j\):

\[ z_j = w_{j1}x_1 + w_{j2}x_2 + b_j \] \[ a_j = \sigma(z_j) = \frac{1}{1+e^{-z_j}} \]

For the output neuron:

\[ z_{\text{out}} = w_1 a_1 + w_2 a_2 + w_3 a_3 + b_{\text{out}} \] \[ \hat{y} = \sigma(z_{\text{out}}) \]

The sigmoid squashes any value into \((0, 1)\), making it interpretable as a probability.

Step 3 — The Loss Function Binary cross-entropy

We measure how wrong the prediction is using binary cross-entropy loss. The loss compares the network's output \(\hat{y}\) to the target \(y\).

Binary cross-entropy

The loss function for binary classification:

\[ L = -[y \log(\hat{y}) + (1-y)\log(1-\hat{y})] \]

When \(y = 1\): \(L = -\log(\hat{y})\) — penalizes \(\hat{y}\) far from 1.

When \(y = 0\): \(L = -\log(1-\hat{y})\) — penalizes \(\hat{y}\) far from 0.

The loss is differentiable — this is essential for backpropagation. We need \(\frac{\partial L}{\partial \hat{y}}\) to start the backward pass.

Step 4 — Gradient at the Output δ = ∂L/∂z

Backpropagation starts at the output. We compute the error signal δ — the gradient of the loss with respect to the pre-activation output. For sigmoid + cross-entropy, this simplifies beautifully.

The error signal

Using the chain rule:

\[ \delta_{\text{out}} = \frac{\partial L}{\partial z_{\text{out}}} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z_{\text{out}}} \]

For cross-entropy loss with sigmoid output, this simplifies to:

\[ \delta_{\text{out}} = \hat{y} - y \]

This elegant result is why cross-entropy is paired with sigmoid. The gradient is simply the prediction error!

Step 5 — Backward Pass Through the Network Chain rule

The error signal propagates backward through the network. Each hidden neuron receives a weighted sum of downstream gradients, multiplied by the derivative of its own activation.

The chain rule in action

For each hidden neuron \(j\):

\[ \delta_j = \frac{\partial L}{\partial z_j} = \frac{\partial L}{\partial a_j} \cdot \sigma'(z_j) \] \[ \frac{\partial L}{\partial a_j} = \sum_k w_k^{(2)} \delta_k \] \[ \sigma'(z_j) = a_j(1 - a_j) \]

So:

\[ \delta_j = \left(\sum_k w_k^{(2)} \delta_k\right) a_j (1 - a_j) \]

The gradient flows backward through the weights, and each neuron's local derivative \(\sigma'(z_j)\) modulates the signal.

Step 6 — Weight Update θ ← θ − α∇L

Finally, we compute the gradient of the loss with respect to each weight and apply gradient descent. Click "Update" to perform one training step and watch the loss decrease.

Gradient of loss w.r.t. weights

For output layer weights:

\[ \frac{\partial L}{\partial w_j^{(2)}} = \delta_{\text{out}} \cdot a_j^{(1)} \]

For hidden layer weights:

\[ \frac{\partial L}{\partial w_{ji}^{(1)}} = \delta_j \cdot x_i \]

Update rule (gradient descent):

\[ w \leftarrow w - \alpha \frac{\partial L}{\partial w} \]
